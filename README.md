# My Finance App v2 Clean Base

Это новая чистая основа приложения под старую Supabase-базу.

## Что входит

Главная:
- Wallet header
- основной счёт
- карточки счетов
- последние операции

Модалки:
- добавить расход
- добавить доход
- создать/редактировать счёт

Логика:
- загрузка `accounts`
- загрузка `transactions`
- загрузка `categories` только для выбора категории расхода
- загрузка `app_meta` для ручных корректировок баланса
- расчёт балансов по операциям
- сохранение операции
- создание/редактирование счёта

## Важно

Это не перенос старой каши. Старые wallet-hard/light, analytics-heavy, safe-buckets, mandatory-payments и прочие большие модули сюда не перенесены.

Supabase anon key лежит в клиенте. Это нормально для фронтенда только при включённом RLS и правильных policies.
